# Claude_Project1

A practice repository for learning the GitHub pull request workflow with [Claude Code](https://claude.com/claude-code).

## Getting started

Clone the repository:

```bash
git clone https://github.com/nohahamza244/Claude_Project1.git
cd Claude_Project1
```

## Contributing

1. Create a branch for your change: `git checkout -b my-change`
2. Commit your work and push the branch.
3. Open a pull request against `main`.
